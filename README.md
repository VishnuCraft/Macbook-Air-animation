# MacBook Air Scroll 🚀  

A smooth scrolling animation effect inspired by Apple's MacBook Air website, built using **React.js, GSAP (GreenSock Animation Platform), and ScrollTrigger**.  

---

## 📌 Features  
✅ Apple-style smooth scrolling animation  
✅ Video playback synced with scrolling  
✅ GSAP-powered scroll interactions  
✅ Fully responsive and optimized
